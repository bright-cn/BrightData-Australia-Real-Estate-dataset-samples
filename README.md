# 澳大利亚房地产数据集样本

<h2>包含 1,000 条记录的样本数据集</h2>

此**澳大利亚房地产数据集样本**包含 **1,000 条记录**，并通过 **Bright Data API** 提取。

## 数据点

| 字段名称 | 描述 |
|------------|-------------|
| `rea_property_id` | 房产挂牌信息的唯一标识符。 |
| `property_type` | 房产类型，例如独立屋、单元房或公寓。 |
| `state` | 房产所在的澳大利亚州。 |
| `postcode` | 房产所在地的邮政编码。 |
| `year_built` | 房产建造年份。 |
| `last_sold_date` | 房产最近一次售出的日期。 |
| `last_sold_agency` | 最近一次售出该房产的房地产中介公司。 |
| `bedrooms` | 房产的卧室数量。 |
| `bathrooms` | 房产的浴室数量。 |
| `findAgentsURI` | 用于查找与房产挂牌信息相关的经纪人的 URL。 |
| `floor_area` | 房产的总建筑面积。 |
| `fullSuburb` | 房产所在郊区的完整名称。 |
| `house_type` | 房屋的具体类型，用于说明其结构特征。 |
| `lat` | 房产所在地的纬度坐标。 |
| `lon` | 房产所在地的经度坐标。 |
| `photo_count` | 房产挂牌信息可用的照片数量。 |
| `images_urls` | 与房产挂牌信息相关的图片 URL。 |
| `street_address` | 房产的街道地址。 |
| `suburb` | 房产所在的郊区。 |
| `url` | 房产在线挂牌页面的 URL。 |
| `land_size` | 房产所在土地的面积。 |
| `sales_history` | 房产的历史销售数据。 |
| `land_size_num` | 土地面积的数值。 |
| `land_size_unit` | 土地面积的计量单位。 |
| `floor_area_num` | 建筑面积的数值。 |
| `avm_estimate_lastUpdated` | 自动估值模型最近一次更新的日期。 |
| `estimated_price` | 房产的预估市场价格。 |
| `estimated_price_confidence` | 预估价格的置信水平。 |
| `estimated_value` | 根据多种因素计算得出的房产价值。 |
| `estimated_value_high` | 房产预估价值的最高值。 |
| `estimated_value_low` | 房产预估价值的最低值。 |
| `offMarket` | 表示该房产目前是否已下市。 |
| `parking` | 房产停车位的详细信息。 |
| `listing_type` | 挂牌类型，例如出售或出租。 |
| `availability` | 房产当前的可用状态。 |
| `rent_price` | 房产的出租价格。 |
| `rent_currency` | 租金所使用的货币。 |
| `rent_bond` | 租赁房产所需的押金金额。 |
| `sold_date` | 房产正式售出的日期。 |
| `property_history_link` | 房产历史数据的链接。 |
| `description` | 房产挂牌信息的详细描述。 |
| `agents` | 管理该房产挂牌信息的经纪人信息。 |
| `branding` | 与房产挂牌信息相关的品牌信息。 |
| `listed_at` | 房产挂牌上市的日期。 |


## 使用场景

### 1. 市场趋势分析
利用该数据集识别和预测澳大利亚房地产市场的趋势，为投资策略和政策制定提供支持。

### 2. 房产估值模型
开发机器学习模型，根据多种因素预测房产价值，提高房地产专业人士的估值准确性。

### 3. 竞争格局评估
通过分析中介公司的销售数据来研究竞争对手的活动和策略，帮助房地产企业改善市场定位。
